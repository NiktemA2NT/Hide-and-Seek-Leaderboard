## Setup

### Schritt 1:
Downloade den Code und installiere Folgende Libraries und Programme:
Programme:
- Python 3.1.x oder höher
- pip (Version sollte egal sein) <---- Zum Installieren der Libaries

Libaries:
> Öffne die Konsole und gebe ein: `pip install flask fastapi uvcorn logging uuid contextlib`
- FastAPI (API)
- uvicorn
- pydantic
- typing
- contextlib

### Schritt 2:
Entpacke den Code und schiebe ihn in einen gewünschten Ordner
> Beispiel: `C:/Users/<your_name>/Documents/Leaderboard`

### Schritt 3:
Öffne die Konsole und gebe folgende Befehle ein!

`cd <pfad>`
`python lead.py` oder `python3 lead.py`

Jetzt sollte der Server unter Folgendem Port laufen: 8084
> Zum Checken kannst du im Browser deiner wahl einfach: `localhost:8084` eingeben um zu checken ob alles läuft!

Wenn ich alles Richtig erzählt habe und du alles korrekt gemacht hast sollte der Server jetzt laufen! Wenn nicht achte auf den Errorcode und den ausgespuckten Fehler!
